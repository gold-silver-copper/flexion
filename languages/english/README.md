# english

English inflection for **any** English word, attested or not: noun plurals, verb
forms, and comparatives and superlatives, each with a confidence.

```rust
use english::*;

assert_eq!(noun("cat", Number::Plural), "cats");
assert_eq!(noun("child", Number::Plural), "children");
assert_eq!(verb("go", VerbForm::Past), "went");
assert_eq!(adjective("good", Degree::Comparative), "better");
assert_eq!(adjective("beautiful", Degree::Superlative), "most beautiful");

// Words nobody wrote down inflect by the patterns learned from those who did.
assert_eq!(noun("glorp", Number::Plural), "glorps");

// Every candidate, with the model's confidence.
let plurals = noun_scored("octopus", Number::Plural);
assert_eq!(plurals[0].form, "octopuses");

// A citation pins principal parts: here, which `lie` you mean.
assert_eq!(verb("lie", VerbForm::Past), "lay");
assert_eq!(verb("lie, lied", VerbForm::Past), "lied");
assert_eq!(verb("lie, lied", VerbForm::PastParticiple), "lied");
```

Agreement, pronouns and possessives are hand-written helpers on top:

```rust
use english::*;

assert_eq!(conjugate("be", Tense::Present, Person::First, Number::Singular), "am");
assert_eq!(conjugate("walk", Tense::Present, Person::Third, Number::Singular), "walks");
assert_eq!(pronoun(Person::Third, Number::Singular, Gender::Feminine, Case::Accusative), "her");
assert_eq!(count_with_number("mouse", 3), "3 mice");
assert_eq!(add_possessive("dogs"), "dogs'");
```

## How it works

This crate was generated by [flexion](https://github.com/gold-silver-copper/flexion) from a
description of English grammar and the Kaikki dumps of the English Wiktionary's
English entries.
For every part of speech, each attested word is reduced to its **inflection class**: the edits
(strip a suffix, add a suffix, maybe add a prefix, place the stress) that turn its lemma into
each of its forms. A suffix tree over lemmas, read from the last letter backwards, stores at
each node how likely each class is for words ending that way. Nodes that add nothing over
their parent are pruned; whole words survive only when they are real exceptions. To inflect a
word, the runtime walks it as deep as the tree goes and applies the most likely class that
fits. Words nobody wrote down get the patterns of the words that end like them; attested words
get their own forms.

Confidences are the tree's smoothed class probabilities. Where Wiktionary lists several
forms for one cell, each later-listed form gets half the weight of the one before, so
confidences between attested variants reflect Wiktionary's ordering, not measured usage.

## Accuracy

Measured by `cargo xtask build english` on the Kaikki dump `English.jsonl` of 2026-10-03. Every number below is
computed through the same runtime this crate ships. A cell counts as right when the top
answer is the **primary** attested form: the first plain form Wiktionary lists for the
first entry with that word. Nonstandard, dialectal, dated and similar forms are never
trained on and never counted.

### Words the model never saw

A tenth of all lemmas (chosen by a hash of the lemma, so every entry of a word goes the
same way) is held out: the model is trained without them, then asked for every form they
attest. Another tenth chose the model's hyperparameters, so the held-out tenth was never
used for any decision.

*english 0.4 rules*: the hand-written regular rules of the published `english` 0.4 (`english-core`), no tables.
*english 0.4 rules + tables*: the whole published `english` 0.4. Its exception tables were built from all of Wiktionary, so it has already seen these "held-out" words: this column is not a measure of generalization.

*Top-3* counts a cell when any attested form is among the three most likely answers.
*Given citation* gives the model the principal parts a dictionary prints with the lemma
(noun `noun.pl`; verb `verb.past` and `verb.pp`; adjective `adjective.comp` and `adjective.sup`; adverb `adverb.comp` and `adverb.sup`) and scores the remaining cells.
