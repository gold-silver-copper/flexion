# russian

Russian inflection for **any** Russian word, attested or not: noun declension,
adjectives (long and short forms), verbs (non-past, past, imperative,
participles, gerunds), with stress, and a confidence for every answer.

```rust
use russian::*;

assert_eq!(noun("книга", Case::Genitive, Number::Plural), "кни́г");
assert_eq!(noun("стол", Case::Genitive, Number::Singular), "стола́");
assert_eq!(adjective("новый", Case::Dative, Agreement::Feminine, Animacy::Inanimate), "но́вой");
assert_eq!(non_past("читать", Person::Third, Number::Plural), "чита́ют");
assert_eq!(past("читать", Agreement::Feminine), "чита́ла");

// Without stress marks:
let plain = Russian::default().stress(false);
assert_eq!(plain.noun("книга", Case::Genitive, Number::Plural), "книг");

// Gender is predicted too, for words the data never saw.
assert_eq!(gender("тетрадь")[0].0, Gender::Feminine);
```

A citation gives principal parts (nominative and genitive singular for nouns;
infinitive and first and second singular for verbs); the rest is predicted to
agree with them.

```rust
use russian::*;

assert_eq!(noun("путь, пути", Case::Instrumental, Number::Singular), "путём");

// Markers name what spelling can't show, as a dictionary prints them after the
// word: gender (`m`, `f`, `n`), animacy (`anim`, `inan`), aspect (`impf`, `pf`).
// They decide for a word the model doesn't know; an attested word keeps its own.
assert_eq!(noun("бокр, бокра m anim", Case::Accusative, Number::Singular), "бо́кра");
assert_eq!(noun("бокр, бокра m inan", Case::Accusative, Number::Singular), "бо́кр");
```

## How it works

This crate was generated by [flexion](https://github.com/gold-silver-copper/flexion) from a
description of Russian grammar and the Kaikki dumps of the English Wiktionary's and of the Russian Wiktionary's
Russian entries.
For every part of speech, each attested word is reduced to its **inflection class**: the edits
(strip a suffix, add a suffix, maybe add a prefix, place the stress) that turn its lemma into
each of its forms. A suffix tree over lemmas, read from the last letter backwards, stores at
each node how likely each class is for words ending that way. Nodes that add nothing over
their parent are pruned; whole words survive only when they are real exceptions. To inflect a
word, the runtime walks it as deep as the tree goes and applies the most likely class that
fits. Words nobody wrote down get the patterns of the words that end like them; attested words
get their own forms.

Confidences are the tree's smoothed class probabilities. Where Wiktionary lists several
forms for one cell, each later-listed form gets half the weight of the one before, so
confidences between attested variants reflect Wiktionary's ordering, not measured usage.

## Accuracy

Measured by `cargo xtask build russian` on the Kaikki dump `Russian.jsonl` of 2026-10-03 and `Русский.jsonl` of 2026-10-02 from the Russian Wiktionary. Every number below is
computed through the same runtime this crate ships. A cell counts as right when the top
answer is the **primary** attested form: the first plain form Wiktionary lists for the
first entry with that word. Nonstandard, dialectal, dated and similar forms are never
trained on and never counted.

### Words the model never saw

A tenth of all lemmas (chosen by a hash of the lemma, so every entry of a word goes the
same way) is held out: the model is trained without them, then asked for every form they
attest. Another tenth chose the model's hyperparameters, so the held-out tenth was never
used for any decision.

¹ A closed class: too few held-out lemmas for these numbers to mean much. What matters for
it is the attested table below.

*Top-3* counts a cell when any attested form is among the three most likely answers.
*Given citation* gives the model the principal parts a dictionary prints with the lemma
(noun `noun.gen.sg`; verb `non_past.1.sg` and `non_past.2.sg`) and scores the remaining cells.
*Citation and markers* also gives the word's inherent features, written as markers after
the word the way a dictionary prints them (noun `m`/`f`/`n`/`anim`/`inan`; verb `impf`/`pf`).
*Lemma written in full* gives the lemma with the marks a dictionary prints (stress,
vowel length); the plain *top-1* column has to guess them too. *Letters right* ignores
those marks.

*adjective*: a lemma typed plain that the `participle` forms of the verbs attest is read as they write it (57877 such
lemmas in the shipped model). 1954 of the 3332 held-out lemmas (58.64%) are among the training
words' forms, so their stress and length come from those tables; their other forms are
still predicted.

The shipped model reads those lemmas from the verb models instead of storing them (the
words they lend are marked as attested there) and keeps only the 31823 entries reading them
gets wrong or would wrongly find: it is smaller that way, with the same answers.

## Regenerating

```sh
# the Russian Wiktionary: https://kaikki.org/ruwiktionary/Русский/kaikki.org-dictionary-Русский.jsonl
cd flexion
cargo xtask build russian --dump kaikki.org-dictionary-Russian.jsonl \
    --edition ru=kaikki.org-dictionary-Русский.jsonl
```
